📚 API Documentation

Base URL

http://127.0.0.1:5000

Endpoints

  • GET /api/health - Check API health status
  • POST /api/predict - Predict medicine for single patient
  • POST /api/predict/batch - Predict for multiple patients
  • GET /api/info - Get model information
  • GET /api/sample - Get sample patient data

Request Example (POST /api/predict)

curl -X POST http://127.0.0.1:5000/api/predict \
  -H "Content-Type: application/json" \
  -d '{
    "age": 25,
    "weight_kg": 68.5,
    "height_cm": 172,
    "body_temperature": 38.6,
    "blood_pressure_systolic": 120,
    "blood_pressure_diastolic": 80,
    "heart_rate": 78,
    "oxygen_saturation": 98,
    "blood_sugar_level": 92,
    "symptom_duration_days": 3,
    "gender": "male",
    "blood_group": "O+",
    "primary_diagnosis": "viral_fever",
    "severity": "mild",
    "age_risk_group": "adult",
    ...
  }'
